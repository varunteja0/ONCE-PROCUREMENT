Security overview

Trust us because the controls are reviewable.

Once handles sensitive insurance operations data for US specialty MGAs: producer profiles, insurance documents, portal activity, consent records, and signed audit evidence. We do not ask customers to trust blindly. We provide technical controls, clear operating boundaries, and reviewable artifacts before a pilot moves live data.

Current production-readiness posture

  • SOC 2 Type I readiness is underway; Once is not yet SOC 2 certified.
  • Live production pilots are scoped to selected portals and explicit customer approval.
  • Security, privacy, and DPA terms are reviewed during pilot contracting.
  • Customers can request a technical review call before sending live data.

Application security

  • Tenant-scoped backend data model and API dependencies.
  • Role-based access controls for submission mutations and cockpit operations.
  • JWT access and refresh-token flow with short access-token lifetime.
  • Production startup checks reject placeholder secrets and mock billing.

Data protection

  • TLS for network transit.
  • Database and object-storage encryption through infrastructure providers.
  • Browser-extension profile vault encrypted locally with WebCrypto AES-GCM.
  • Least-privilege operational access for customer support and debugging.

Audit evidence

  • Ed25519-signed submission receipts over canonical JSON.
  • Public verifier and public-key endpoint for independent validation.
  • Tenant audit trail for consent, submission, receipt, and export events.
  • Nightly E2E verification workflow for receipt/verifier drift.

Operational controls

  • Structured logs, Sentry observability, and health checks.
  • Security headers on the public landing site.
  • Explicit human-in-the-loop handling for captcha and risky portals.
  • Documented incident response and retention practices.

What we still disclose honestly

Once is in a pilot-readiness phase. We do not claim completed SOC 2, universal portal coverage, legal admissibility of every receipt, or zero-risk automation. Customers get the current security packet, subprocessors, retention terms, and pilot scope before launch.

Security review requests, vulnerability reports, and questionnaire requests should go to security@getonce.com.
